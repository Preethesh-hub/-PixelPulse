# VisioQuest

VisioQuest is a responsive web application designed to help users discover the world's imagery in seconds. Once fully built, it will fetch and display images in a dynamic grid based on user search queries. 

**Design Decisions:**
1. **Sticky Header**: I implemented a sticky header (`position: sticky`) so the search bar is always accessible to the user, no matter how far down they scroll through the image results.
2. **Result Count Placeholder**: I added a result count text placeholder to clearly communicate the app's status to the user (e.g., waiting for search, number of items found) without them having to guess.
3. **Dark Theme**: Instead of the reference's purple theme, I opted for a modern dark theme with teal (`#00b4d8`) and gold (`#ffb703`) accents to make the images eventually pop more vividly against the background.
